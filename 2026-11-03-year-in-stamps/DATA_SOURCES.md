# Geographic data sources

The destination catalog (`public/data/catalog.v1.json`) is generated by
`scripts/build-catalog.mjs` from the open datasets below. No ids, names or codes
are hand-written, except a small `MOTIF_OVERRIDES` table (`src/lib/catalog/snapshot.ts`)
that picks decorative motifs for some well-known places, and the Phase 1
migration table (`src/lib/catalog/legacy.ts`), whose ids were looked up in the
generated catalog.

| Dataset | Files used | Version | Licence |
| --- | --- | --- | --- |
| [GeoNames](https://www.geonames.org/) | `countryInfo.txt`, `admin1CodesASCII.txt`, `cities15000.zip` | Daily export downloaded 2026-11-03 | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| [Natural Earth](https://www.naturalearthdata.com/) | 1:10m Admin 0 – Countries, 1:10m Admin 0 – Map Units (GeoJSON from `nvkelso/natural-earth-vector`, `master`) | 5.2.0-pre | Public domain |

- **Natural Earth:** public domain, no attribution required. We credit it anyway.

## What each source contributes

- **GeoNames `countryInfo`:** the 250 countries and territories (ISO 3166-1
  alpha-2 code, name, population). The withdrawn codes `CS` (Serbia and
  Montenegro) and `AN` (Netherlands Antilles) are skipped.
- **Natural Earth:** classifies each ISO code as a sovereign country or a
  **territory**, using `SOVEREIGNT` vs `ADMIN`, and supplies extra name forms
  (e.g. "Republic of Korea"). Codes that the Countries file folds into their
  sovereign (French Guiana, Svalbard, Tokelau, …) come from the Map Units file.
  For example, Hong Kong is `TYPE: Country`, `SOVEREIGNT: China`, so it becomes a
  territory with designation "Special Administrative Region of China", not a
  sovereign state. Territory and sovereignty labels follow Natural Earth's de
  facto classification.
- **GeoNames `cities15000`:** every populated place with at least 15,000
  people, with its GeoNames id, country, state/province and alternate spellings.
  - Kept: plain-ASCII Latin alternate names (e.g. Pusan, Bombay, Saigon).
    Accented variants are covered by accent-insensitive search.
  - Skipped:
    - city sections, historical, abandoned and destroyed places (feature codes
      `PPLX`, `PPLH`, `PPLQ`, `PPLW`, `PPLCH`);
    - same-name duplicates within one region;
    - numbered districts of a listed city (Paris 15 Vaugirard, Marseille 08);
    - capitals that share their name with a territory smaller than 2,000 km²
      (Hong Kong, Singapore, Monaco), which are represented by the territory itself.

## Identifiers

- Countries and territories: `iso:<ISO alpha-2>`, e.g. `iso:KR`, `iso:HK`.
- Cities: `gn:<GeoNames id>`, e.g. `gn:1838524` (Busan).

These ids are stored in saved passports, so they must stay stable. Each saved
stamp also keeps a snapshot of its place's name, country and motif, so a future
catalog update cannot break an existing passport.

## Regenerating

```bash
npm run catalog -- --download   # fetch the sources into data/raw/ and rebuild
npm run catalog                 # rebuild from data/raw/ (already downloaded)
npm test                        # the search tests run against the generated file
```

`data/raw/` is git-ignored. The generated JSON is about 2.4 MB (about 950 KB
gzipped). The browser fetches it once, and only on the passport page.

## Known gaps

- Places under 15,000 people aren't included.
- Alternate names are Latin-script only; searching in Korean, Japanese or
  Chinese script (서울, 東京) doesn't match yet.
